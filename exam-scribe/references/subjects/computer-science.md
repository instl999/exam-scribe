# Subject profile: computer science

- **Priorities:** definitions, algorithms (steps, invariants, complexity), data structures and their
  operation costs, code semantics, and the book's worked examples.
- **Algorithms:** a `process` block for the steps; complexity claims copied exactly with their conditions
  ("average case", "amortized", "for a sorted array").
- **Code tracing:** `trace` blocks with one fenced code block, `lang:`, the exact `output:` and a cited `why:`.
  If `checks.run_code` is true and the language is Python, the script can run the snippet to confirm the output.
- **Comparisons:** array/linked list, BFS/DFS, stack/queue, compile-time/run-time: `compare` rows per property
  (access cost, memory, ordering).
- **Questions:** tracing ("what does this print?"), complexity mcqs, "which data structure fits" questions,
  find-the-bug questions at the analyze level.
